# Music Analysis Project

## Description

This project analyzes music trends using data from Spotify, Genius, and MusicBrainz. It includes data collection, cleaning, analysis, machine learning (clustering), and visualization.

## Setup

1.  **Install Dependencies**:

    ```bash
    pip install -r requirements.txt
    ```

2.  **API Keys**:

    - Copy `.env.example` to `.env`.
    - Fill in your Spotify Client ID/Secret and Genius Access Token.

3.  **Run the Pipeline**:
    ```bash
    python main.py
    ```

## Project Structure

- `core/`: Contains all logic modules.
- `data/`: Stores raw and processed data.
- `figs/`: Generated figures.
- `reports/`: Generated PDF dashboard.
- `logs/`: Execution logs.

## Features

- **Data Collection**: Fetches tracks and audio features from Spotify.
- **Text Analysis**: Generates word clouds from song titles/metadata (Lyrics placeholder).
- **Audio Analysis**: Analyzes BPM, energy, danceability.
- **Machine Learning**: Clusters songs into styles using KMeans.
- **Visualization**: Generates a PDF report with charts.
